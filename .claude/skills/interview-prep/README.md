# 면접준비 — 팀장용 한 줄 설치

이력서 PDF와 실제 채용 공고를 바탕으로 후보별 면접질문·잠정 평가·로컬 PDF 뷰어를 준비하는 Claude Code 스킬입니다. 실제 후보 자료나 회사 내부정보는 포함하지 않습니다.

## 1. 설치

Claude Code, Git, **Node.js 22.20 이상**이 설치된 PC의 터미널에서 실행합니다. Node 버전은 `node --version`으로 확인합니다. 현재 `skills` 설치 도구의 요구 버전이며, 스킬 자체의 Node 스크립트는 18 이상에서 실행됩니다.

```bash
npx skills add hg-source/hc-team-skills --skill interview-prep -a claude-code -g --copy
```

설치 확인 질문을 승인하면 **면접준비 하나만** 사용자 영역에 복사됩니다. 다른 스킬이나 프로젝트 전체를 설치하지 않습니다. 같은 이름의 기존 스킬을 직접 수정해 사용 중이면 먼저 그 폴더를 날짜가 붙은 백업으로 복사하세요. 설치기가 기존 사본을 교체할 수 있습니다.

`skills`는 Vercel의 오픈소스 [설치 CLI](https://github.com/vercel-labs/skills)이며 Claude Code 내장 명령은 아닙니다. 공개 저장소 설치에는 별도 사내 계정·API 키가 필요하지 않습니다. Claude Code 자체 이용 조건은 별도입니다.

## 2. 사용

이력서를 Downloads에 두고 Claude Code의 새 대화에서 요청합니다.

> 다운로드 폴더의 홍길동 이력서로 면접준비해줘. 지원 직무는 상품기획 팀장이야.

파일명에 이름·직무가 분명하면 이름만 말해도 됩니다. 동명이인이나 공고가 여러 개면 확인이 필요합니다. 여러 후보도 각각 준비할 수 있습니다. JD 파일·텍스트가 있으면 함께 제공하세요.

**설치 명령은 스킬 파일만 설치합니다.** 첫 면접준비 요청 때 Claude Code가 초기화 스크립트를 실행해 사용자 홈의 `Documents/EGNIS 면접도구` 폴더에 빈 도구를 만들고, 이력서를 읽어 질문·평가·시드를 생성합니다. 기존 작업 폴더를 쓰려면 요청에 경로를 명시하세요.

PDF 읽기에 필요한 도구가 없는 환경에서는 Claude Code가 추가 도구 또는 텍스트 제공을 요청할 수 있습니다. Node·Git만으로 PDF 텍스트 추출까지 보장하지는 않습니다.

완료 후 안내받은 `면접툴.html`을 브라우저에서 엽니다. 좌측 PDF·우측 질문/평가를 확인합니다. PDF 자동 표시가 막히면 툴의 PDF 추가 버튼으로 파일을 선택하세요.

## 기록 보존과 개인정보

- 스크립트는 기존 파일이 달라질 때 날짜 백업을 남깁니다. 재초기화로 기존 시드·PDF·질문·평가를 지우지 않습니다.
- 면접 메모·점수는 해당 브라우저의 로컬 저장소에 남습니다. **브라우저를 바꾸거나 데이터를 지우기 전에 JSON 내보내기를 하세요.** 변경된 질문의 이전 기록도 JSON의 `questionHistory`에서 보관합니다.
- HTML 도구에는 서버 업로드 기능이 없습니다. Claude Code의 이력서 분석은 사용 중인 AI 서비스의 데이터 처리 정책을 따릅니다. 회사의 개인정보 처리 기준에 맞게 사용하세요.
- 후보 이력서·질문·평가·시드·JD 캐시는 각 PC 작업 폴더에만 둡니다. GitHub에 올리지 마세요.
- AI 평가는 잠정 참고자료이며 최종 채용 판단은 면접관이 합니다.

## 업데이트

설치한 사본을 직접 수정했다면 먼저 백업하고 아래 명령을 실행합니다. 자동 업데이트가 아니라 실행 시 갱신됩니다.

```bash
npx skills update interview-prep -g
```

스킬 수정은 정본에서만. 에이전트별 폴더 직접 수정 금지.

## 유지보수 검증

스킬 폴더에서 `node --test tests/portable.test.cjs`를 실행합니다. 테스트는 가상 자료만 임시 폴더에 생성하며, 원본·테스트 폴더를 삭제하지 않습니다.
