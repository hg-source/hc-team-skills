# 질문에 맞는 검색과 근거 평가

전체 체크리스트를 매번 출력하지 않는다. 해당 질문에 필요한 방법만 선택한다.

## 검색 경로

주요 개념과 동의어, 고객의 사용 상황·불편, 대체재를 구분한다. 질문의 모든 조건을 한 검색식에 넣으면 관련 자료를 놓칠 수 있다. OR/AND 등은 해당 검색 서비스가 지원하는 경우에만 사용한다. 조사 범위가 한국이면 한국어와 국내 자료원을 먼저 보고 해외는 비교 근거로 표시한다.

검색 로그에는 중요한 검색어·서비스·검색일·제한·다음에 바꾼 이유를 남긴다. 모든 클릭을 별도 문서로 만들 필요는 없다. 일반 검색→자료원 지정→반례/실패→핵심 원출처와 인용 추적의 경로를 필요에 맞게 사용한다.

## 근거의 단위

- 출처: 제목·URL·발행/관측일·확인일·원출처 관계. 개인정보와 원문 전체를 무분별하게 복제하지 않는다.
- 관찰: 해당 절·표·행·짧은 발췌와 실제로 확인한 내용. 상품 리뷰는 게시일과 제품/채널을 식별한다.
- 해석: 관찰이 질문에 주는 의미와 적용 한계. 여러 출처의 일치가 같은 원자료의 반복인지 확인한다.
- 가설: 아직 검증되지 않은 연결과 무엇을 보면 약화/반박되는지.

숫자는 기간·단위·분모·대상·방법이 맞는지 확인한다. 평균과 개별 제품, 판매액과 판매량, 후기의 재구매 진술과 거래 기반 재구매율을 혼동하지 않는다. 공식 제품 페이지는 판매자 주장/표시의 근거이며 독립 효능 검증은 아니다.

## 고객과 트렌드

최근 구매·비교·전환·포기 사례를 확인한다. 긍정과 부정 진술을 함께 보고 모집/검색 편향과 보상 여부의 미확인을 밝힌다. 후기를 분류해도 전체 고객의 빈도로 일반화하지 않는다. 실제 행동 자료가 없다면 다음 인터뷰/시험 설계까지만 제안한다.

초기 트렌드는 인접 분야·다른 채널·고객 표현의 변화도 탐색한다. 근거가 약한 신호는 관찰 후보이며 수요 확정이 아니다. 낯선 것만 찾으려고 이미 검증된 중요한 사실을 버리지 않는다.

## 적용성과 후속 검증

국가·고객·가격·채널·기간 차이 중 결론에 중요한 조건을 적는다. 해외 사례, 창업자 회고, 임상 연구가 각각 국내 수요·인과·완제품 효능을 입증한다고 확대하지 않는다.

실험을 제안할 때에는 바꿀 요인, 비교 조건, 성공 지표, 악화되면 안 되는 지표와 관찰 기간을 목적에 맞게 정한다. 최소 표본이나 PMF 수치를 보편 규칙으로 고정하지 않는다. 실제 집행은 승인 후이며 결과 관측 전 예측·판정 기준을 보존한다.

## 방법론 출처와 적용 한계

- [Cochrane 검색 지침](https://www.cochrane.org/authors/handbooks-and-manuals/handbook/current/chapter-04): 검색 경로와 누락 점검을 선별 적용. 정식 체계적 문헌고찰을 수행했다고 부르지 않는다.
- [PRISMA-S](https://link.springer.com/article/10.1186/s13643-020-01542-z): 검색 보고의 투명성 참고. 전체 양식 준수나 품질 인증이 아니다.
- [GOV.UK 사용자 조사](https://www.gov.uk/service-manual/user-research/using-in-depth-interviews): 실제 경험·중립 질문 참고.
- [GO-Science Horizon Scanning](https://www.gov.uk/government/publications/futures-toolkit-for-policy-makers-and-analysts/the-futures-toolkit-html#horizon-scanning): 약한 신호·후속 질문 참고.
- [Microsoft 실험 전 단계](https://www.microsoft.com/en-us/research/articles/patterns-of-trustworthy-experimentation-pre-experiment-stage/): 가설·성공 및 보호 지표 참고. 식품 성공률을 입증하는 자료는 아니다.
