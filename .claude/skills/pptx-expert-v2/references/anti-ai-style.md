# Anti-AI Style Rules

## Hard Fail

- 동일 `layout_family` 2장 연속
- 표지·구분면 외 주제어 제목
- card-grid가 전체의 30% 초과
- 장식용 gradient/glow
- 제목 아래 의미 없는 accent line
- 모든 불릿에 아이콘
- 전체 슬라이드를 이미지로 삽입
- 출처 없는 수치와 임의 추정
- 외부 브랜드 template·logo·character 무단 복제

## Visual Smells

- 모든 요소의 radius와 shadow가 같음
- 2×2 또는 3-column card grid 반복
- 페이지마다 큰 숫자 3개
- 모든 내용이 완전 대칭
- 제목·본문·caption의 크기 차이가 작음
- 긴 설명이 작은 글씨로 card 안에 갇힘
- 색이 의미가 아니라 섹션 구분용 장식으로만 사용됨
- 차트가 해석 없이 중앙에 놓임
- 표가 화면을 가득 채우지만 강조 row가 없음

## Humanization Tactics

- 완벽한 대칭 대신 메시지 비중에 맞춘 7:5, 8:4 비율
- evidence density를 페이지마다 변화
- 핵심 문장을 표 바깥 margin annotation으로 강조
- one-off illustration보다 data/decision annotation 우선
- rule, alignment, whitespace로 그룹 형성
- 비교 기준이 없는 큰 숫자는 작은 본문으로 낮춤
- 같은 정보라도 role이 다르면 layout을 바꿈

## Review Questions

1. 이 slide가 빠지면 의사결정이 달라지는가?
2. 제목만 읽어도 결론이 보이는가?
3. 시각물 하나가 제목을 증명하는가?
4. 강조색을 제거해도 정보 위계가 남는가?
5. PowerPoint에서 사람이 5분 안에 수정할 수 있는가?
6. 다른 산업의 deck으로 내용만 바꿔도 똑같아 보이지 않는가?
