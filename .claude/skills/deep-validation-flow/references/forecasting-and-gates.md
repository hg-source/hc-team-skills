# Forecasting and decision gates

## Outside view first

Before forecasting the focal case, define a reference class of comparable initiatives. Record selection criteria, base rates, and known differences. Then apply inside-view adjustments explicitly.

Do not use a reference class so broad that it becomes meaningless or so narrow that it contains only successes.

## Forecast ledger

For every decision-relevant prediction record:

- Forecast ID, metric, time horizon, base rate or reference class.
- Point estimate and low/base/high range.
- Confidence and key assumptions.
- Evidence and model or calculation path.
- Resolution date, actual value, and scoring method.

Prefer ranges to false precision. Use probabilities only when the event and resolution rule are unambiguous.

## Minimum quantitative analysis

For commercial decisions, include as applicable:

- Price, volume, conversion, repeat, revenue, gross margin, and contribution margin.
- Full variable economics: production, freight, warehousing, payment, promotion, CAC, returns, loss, and servicing.
- Capacity, MOQ, lead time, yield, shelf life, and working capital.
- Conservative, base, and aggressive scenarios.
- One-way and, where useful, two-way sensitivity on the dominant assumptions.

Unknown figures must be labeled `산정 필요` or `확인 필요`; do not invent them to complete a model.

## Value of information

Prioritize a test when:

`decision-change probability × avoided loss or captured upside > test cost + delay cost`

Use this as a ranking logic, not as fake precision. Stop further research when likely outcomes no longer change the option, gate, timing, or risk control.

## Gates

Define observable thresholds before validation:

- **Kill gate**: evidence that stops the option.
- **Pivot gate**: evidence that changes formulation, customer, channel, price, or method.
- **Scale gate**: evidence that authorizes larger commitment.
- **Review gate**: evidence requiring human or specialist judgment.

Each gate needs metric, threshold, measurement method, owner, date, and action. A test without a precommitted action rule is learning theater.
