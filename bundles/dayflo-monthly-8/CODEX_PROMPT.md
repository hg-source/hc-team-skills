# 데이플로 PC의 Codex에 전달할 명령문

아래 문단을 그대로 복사해 데이플로 PC의 Codex에 보냅니다.

---

이 공개 배포본의 월간 8개 스킬을 현재 PC의 통합 스킬 정본에 설치해줘:
https://github.com/hg-source/hc-team-skills/tree/main/bundles/dayflo-monthly-8

대상은 agent-reach, deep-search, deep-validation-flow, deepflow, night-mode, visual-deck, ppt-deck, pptx-expert-v2 총 8개야. 먼저 실제 워크스페이스와 Codex·Claude Code·Hermes의 현재 스킬 경로 및 정본/정션 구조를 읽기 전용으로 확인해. 동일 이름 폴더가 있으면 내용을 비교하고, 교체가 필요하면 삭제하지 말고 폴더 전체를 *_backup_YYYYMMDD_HHMMSS로 보존해. 공개 저장소의 manifest SHA-256을 검증한 뒤 8개만 통합 정본에 설치하고, 기존 에이전트별 연결 구조를 유지해. 개인 경로·Notion 연결값·토큰은 새로 넣지 마. 설치 후 Codex와 Claude Code의 새 세션에서 스킬 이름과 대표 트리거가 인식되는지 확인하고, Hermes는 실제 로드 경로까지 확인해. 예약 작업이나 자동 업데이트는 만들지 말고 결과와 미검증 항목을 보고해.
